# Koikatsu Sunshine 简体中文汉化补丁

基于 [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator) / ResourceRedirector 框架制作的《Koikatsu Sunshine（恋活 Sunshine）》简体中文本地化文本，由人工+AI校对整理，非纯机翻。

> ⚠️ 本汉化涉及成人向（R18）内容，请确认你已达到当地法定年龄再使用。

---

## 目录结构

本仓库根目录为 `zh/`，与 XUnity.AutoTranslator 的语言目录一一对应：

```
zh/
├── RedirectedResources/     # 精确匹配游戏资源的翻译（优先级最高，推荐优先维护）
│   └── assets/abdata/
│       ├── action/          # 动作/交互相关文本
│       ├── adv/             # 剧情/对话流程文本（数量最多）
│       ├── communication/   # 交流系统文本
│       ├── custom/          # 角色编辑相关文本
│       ├── etcetra/         # 杂项文本（称呼、话题等）
│       ├── h/                # H 场景相关文本
│       ├── list/            # 各类列表数据（物品、服装、场景信息等）
│       └── map/             # 地图相关文本
├── Text/                     # 通用文本替换，游戏启动时整体加载
│   ├── 插件翻译/             # BepInEx 插件/Mod 提示文本汉化（如 Detection.txt）
│   ├── 菜单界面/             # 主菜单、存读档、角色编辑、H 场景菜单等 UI 文本
│   ├── 角色对话/             # 按人格分类的角色对话文本（40 组 + 补充文件）
│   ├── _AutoGeneratedTranslations.txt  # 机翻自动生成的缓存（预留）
│   ├── _Preprocessors.txt    # 翻译前处理规则
│   ├── _Postprocessors.txt   # 翻译后处理规则
│   └── _Substitutions.txt    # 文本替换规则
└── Texture/                   # 翻译贴图
    ├── 工作室的图标汉化/       # Studio（工作室）模式图标汉化
    └── Texture-Game/          # 游戏内 UI 图标汉化
```

`RedirectedResources` 与 `Text` 的区别遵循 XUnity.AutoTranslator 的约定：前者按资源文件精确匹配，加载更快也更稳定；后者按场景/正则匹配，灵活但依赖运行时抓取，主要用于覆盖 UI 类文本。

仓库根目录下的 `zh/` 为可直接放入游戏的翻译文件，另有 `对照术语表.md`、`README.md`、等非游戏文件，无需放入游戏目录。

## 对照术语表

[`对照术语表.md`]记录了称谓、界面用语、场景活动、成人场景用语、人名专名、场景条件提示等类别下的统一译法约定，以及外来语的写法规则，用于保证各文件、各人物之间译名和用词的一致性。

修订或补充翻译前建议先查阅该表：已有词条应沿用统一译法；如需新增或调整统一译法，请在对应分类表中补充并说明理由，避免同一原文出现多种译法。

## 使用前置条件

- 已安装 [BepInEx](https://github.com/BepInEx/BepInEx)
- 已安装并启用 [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator)（建议同时启用 ResourceRedirector 功能）
- 拥有 Koikatsu Sunshine 游戏本体（本仓库**不包含**游戏本体、官方美术或音视频资源，仅包含收集整理并校对过的翻译文本与贴图）

## 安装方法

1. 下载并解压本仓库
2. 将整个 `zh` 文件夹放入游戏目录下的：
   ```
   BepInEx/Translation/zh/
   ```
3. 打开 `BepInEx/config/AutoTranslatorConfig.ini`，确认：
   ```ini
   [General]
   Language=zh
   ```
4. 启动游戏，若翻译未生效，检查 AutoTranslator 的日志确认路径与语言代码是否匹配

- 本仓库的原始文本与翻译贴图均来自网络上流传的汉化整合包，并非本人从零翻译/制作，本人在此基础上进行了通读校对与整理

- 受限于本人校对水平及AI偶尔抽风，译文中难免存在疏漏、理解偏差或用词不够准确之处，也可能有部分游戏内文本尚未收录或覆盖不全
- 欢迎其他人员对已有文本进行修订，或补充尚未收录的内容，共同完善这份汉化
- 若发现翻译错误或用词不当，欢迎提交 Issue 或 Pull Request；修改前请先查阅 [`对照术语表.txt`](./对照术语表.txt)，沿用其中的统一译法
- 提交 PR 前请勿改动文件编码（保持 UTF-8），并尽量避免调整未涉及改动的行，方便后续合并新版本的文本 dump
